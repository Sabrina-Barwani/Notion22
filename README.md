<h2>✨ Why “Motion”?</h2>
<p>
  <b>Motion</b> is a responsive showcase website built for videographers to present their best work with a clean,
  cinematic vibe. It focuses on <b>visual storytelling</b>, smooth interactions, and a minimal design that keeps
  attention where it belongs — on the content.
</p>

<h2>🚀 Features</h2>
<ul>
  <li>🎬 Cinematic layout focused on reels and highlights</li>
  <li>📱 Responsive design (mobile → desktop)</li>
  <li>🎞 Smooth UI motion using CSS transitions + JS interactions</li>
  <li>🖼 Showcase / gallery section for projects</li>
  <li>⚡ Lightweight and fast (no frameworks)</li>
  <li>🎨 Easy to customize colors, fonts, and sections</li>
</ul>

<h2>📸 Customization Guide</h2>
<ul>
  <li>Replace <b>assets/videos</b> with the videographer’s reels</li>
  <li>Update brand colors in <b>css/style.css</b></li>
  <li>Edit text content in <b>index.html</b> (About / Services / Contact)</li>
  <li>Adjust interaction behavior in <b>js/script.js</b></li>
</ul>
